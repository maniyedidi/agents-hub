# Sample documents

`nimbus-handbook.pdf` is a fictional employee handbook (text layer, ~2 KB of text) for trying the PDF memory upload with a document-Q&A agent. `nimbus-handbook.txt` is its source.

Upload it from an agent's **Files / Memory** dialog, then ask questions such as:

- How many days of annual leave do employees get, and how many can be carried over?
- What is the hotel limit per night, and who approves claims above 50,000 INR?
- How fast must a Severity 1 incident be answered?
- Who founded Nimbus Cloud, and where is the headquarters?
- What is the dress code? (not in the document; the agent should say it couldn't find it)

PDF upload support is added in PR #10.
